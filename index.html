Cómo añadir un informe nuevo

Basta un informe HTML generado con el mismo formato (el que lleva sus datos en window.DATOS). Una sola orden crea el panel, los datos y la ficha en la portada.

  1. Copia el informe a tu equipo y ejecuta (necesita Node 18 o superior, sin dependencias):
node tools/add-report.mjs ruta/al/INFORME.html --slug mi-informe --titulo "Título corto" --resumen "Una frase" --caso "Nombre del caso"
  1. Revisa el resultado abriendo report.html?r=mi-informe con cualquier servidor estático.
  2. Súbelo con git add . && git commit && git push. GitHub Pages lo publica solo.
